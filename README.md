# SHAR Production Verification Workflows

Twenty-five bilingual executable production verification workflows by **[SHAR Production](https://sharprod.com/)**.

Each workflow provides five ordered steps, declared inputs, a deterministic runner, EN/RU interactive pages and a clearly synthetic example. The collection covers intake, approvals, rights, consent, suppliers, on-set handoffs, post-production, localization, delivery, archive and release evidence.

Run `npm run check`. Code and documentation use MIT. Synthetic fixtures use CC-BY-4.0. No client data, media, credentials, analytics or outcome claims are included.
